# Malee Romania Food Importers & Distributors

A static map and directory of Romanian food and beverage importers and distributors, built as a Malee Group mock-up for juices, coconut water, canned fruit and plant milk.

**Live:** https://piyaster11.github.io/malee-romania-importers/

Figures are 2025 annual-account turnovers and employee counts, republished from Ministry of Finance / ONRC filings. Map pins are geocoded with OpenStreetMap Nominatim; approximate coordinates are labelled. Sample reasoning (the best-fit shortlist) is an internal discussion aid, not an approved partner list and not due diligence.

GitHub Pages is served from `docs/` on `main`. The page is a single self-contained `docs/index.html`.
